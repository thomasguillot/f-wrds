title: Insertion

F Wrds can insert text in two ways.

- **Paste** is fast and exact. It is the default.
- **Typed** types the text key by key. Use it for apps that do not accept a paste, mostly terminals.

With Paste, F Wrds borrows the clipboard for a moment to insert the text, then puts back what was there before.

## Set the default method

Go to **Settings → Insertion** and choose **Paste** or **Typed** under **Default method**.

## Exceptions by app

To use a different method in one app:

1. Under **Exceptions by app**, click **Add App…**.
2. Pick the app.
3. Choose **Paste** or **Typed** for it.

Click the minus button to remove an exception. Every app without an exception uses the default method.

## Which to pick

Leave the default on Paste unless an app ignores it. If a snippet does nothing in one app but works in others, add that app as an exception and set it to **Typed**.

See also [Troubleshooting](/docs/troubleshooting).
